# 最终语音转写展示设计

## 目标

在现有语音按钮旁明确展示浏览器最终识别出的文字，让用户能区分“麦克风听到了什么”和“系统理解并执行了什么”。

## 交互

- 聆听期间只显示“正在聆听…”，不展示临时转写。
- 浏览器返回最终结果后，一次性展示完整文本，并提交现有语音解析 API。
- 桌面端转写区位于麦克风右侧；小屏幕位于麦克风下方。
- 再次开始聆听时清空上一条转写。
- 没有最终文本或识别失败时不提交空指令。
- 转写只保存在当前组件状态，不增加数据库写入。
- 现有本地指令、StepFun 来源和执行结果反馈保持不变。

## 实现边界

新增纯函数从浏览器的结果集合中提取并合并最终文本，忽略非最终结果。`VoiceInput` 使用该函数更新转写状态，并用固定尺寸的响应式布局展示。功能不修改硬件协议、StepFun Prompt 或语音 API。

## 验收

- 多段最终结果按顺序合并。
- 非最终结果被忽略。
- 空白文本返回空字符串且不提交。
- 桌面和移动端无重叠或横向溢出。
- 测试、类型检查、ESLint 和生产构建通过。
