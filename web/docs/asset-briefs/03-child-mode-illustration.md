# 素材 03 · 儿童模式插画 ×1

## 用途
品牌展示页「成人·儿童双模式」一屏的儿童侧配图;功能区儿童模式也可复用作空状态插画。

## 规格
- **尺寸**:2000 × 1250(16:10)
- **格式**:JPG 或透明底 PNG(优先透明底,叠加更灵活)
- **色调**:与整站一致——深靛夜空(`#131539`)+ 暖象牙(`#F3EAD8`)+ 月色金(`#F5DFAE`),点到为止的一点暖橙
- **风格**:安静的绘本感,笔触柔和,不要儿童卡通的高饱和,气质要能和展示页的高级感同框

## 提示词
```
Soft dreamy storybook illustration of a sleeping baby in a crib under warm moonlight, a gentle crescent moon glowing above, deep indigo night palette with warm ivory and soft gold accents, minimal composition with lots of quiet negative space, tender and serene, muted colors, no text
```

## 负面提示词
```
bright saturated colors, cartoon outline style, busy background, text, watermark, scary, photorealistic
```

## 交付
放入 `public/assets/illustrations/`,交付名 `child-sleep.png`(或 `.jpg`)。

## 验收标准
- 放在深靛夜空底上不突兀,色系融合
- 情绪是「安心、被守护」
- 大面积留白,文字可以压在旁边
