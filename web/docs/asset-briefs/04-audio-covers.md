# 素材 04 · 助眠音频封面 ×4

## 用途
功能区「助眠资源」模块的音频封面(冥想 / 轻音乐 / 白噪 / 自然声)。会以圆角方卡形式出现在夜色界面上。

## 统一规格
- **尺寸**:800 × 800(1:1)
- **格式**:JPG
- **色调**:深靛 + 暖金的抽象渐变,与整站同一夜色体系
- **风格**:抽象、流动、极简,像高端冥想 App 的专辑封面;四张构成一个系列,靠形态区分不靠颜色跳变
- **禁止**:文字、具象人物、高饱和撞色

## 通用负面提示词(每张都加)
```
text, letters, watermark, people, high saturation, neon, busy pattern, photorealistic
```
